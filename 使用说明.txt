Kimi 雅思单词本整理器（图形版）

【最推荐：生成独立 EXE】
1. 解压整个文件夹，不要只单独拿出某一个文件。
2. 双击“build_exe.cmd”。
3. 第一次会自动安装依赖并打包，通常需要几分钟。
4. 成功后会自动打开 dist 文件夹。
5. 以后直接双击 dist\Kimi雅思单词本整理器_太阳版.exe，不需要打开 VS Code。
6. 可以右键 EXE → 显示更多选项 → 发送到 → 桌面快捷方式。

【先测试图形界面】
双击“run_gui.cmd”。它同样不需要打开 VS Code，但仍依赖当前文件夹里的 .venv 和源代码。

【软件使用流程】
1. 点击“选择文件”，选择原始英文单词记录 .docx 或 .txt。
2. 选择输出目录。
3. 输入 Kimi API Key。Key 只保存在当前输入框中，不写入磁盘。
4. 模型默认使用 kimi-k2.6；也可以点击“刷新列表”。
5. 一般不要启用深度思考，可以节省时间和费用。
6. 点击“开始整理”，确认 API 费用。
7. 完成后直接打开生成的 Word。

【整理规则】
软件首次运行会把默认规则复制到：
%APPDATA%\KimiWordlistTool\rules.txt

可在软件中点击“打开整理规则”修改；点击“恢复默认规则”可还原。

【输出内容】
除最终 Word 外，输出目录还会保留两份调试文件：
- Kimi 原始 JSON
- 结构化 JSON
它们便于排查遗漏或格式问题。

【输入文件】
- 支持 .docx Word 文档。
- 支持 .txt 纯文本文件。建议使用 UTF-8 编码；软件也会尝试读取 UTF-8 BOM、UTF-16 和常见中文 Windows 编码。

【常见情况】
- Windows 可能提示“未知发布者”：这是因为本地生成的 EXE 没有购买数字签名，不代表程序有问题。
- 输入 API Key 时不会被保存。
- 调用 Kimi API 会从你的开放平台余额中按量扣费。
- 首次建议先用较短文档测试。
